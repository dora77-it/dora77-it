# AI Travel Planner (MVP Skeleton)

## 1) 설치
```bash
npm install
```

## 2) 실행
```bash
npm run dev
```

## 3) 페이지
- `/`: 검색 폼
- `/itinerary`: 일정 결과 + OpenStreetMap 지도 뷰

## 4) 지도 데이터
- 지도는 OpenStreetMap 임베드(`openstreetmap.org/export/embed.html`)를 사용합니다.
- 일정 카드의 장소 라벨을 클릭하면 OpenStreetMap 상세 위치 페이지로 이동합니다.
