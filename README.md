## What is this?
**Gordonte's AI Cabinet** is a workflow assistant for Whisk AI.
It helps you run repetitive image-generation tasks automatically with less manual work.

## Core Features
- Batch prompt queue execution
- Automatic image download
- Retry for temporary failures
- Multi-version operation mode

## Supported Languages (Only 3)
1. Korean
2. English
3. Japanese

## Quick Start (Chrome Extension)
1. Install the extension in Chrome/Edge/Brave.
2. Open the extension from your toolbar.
3. Choose a mode/version.
4. Paste prompts or import a `.txt` file.
5. Click **Start**.

> Recommended: Turn off "Ask where to save each file before downloading" in browser settings.

## Budget Alternative: Can I automate without a Chrome extension?
Yes. You can build a **non-extension automation flow** for Whisk image generation.

- Use Playwright/Selenium scripts to automate browser actions (prompt input, run, save).
- Keep it low-cost by starting with small prompt batches and basic retry logging.
- Add rate limits and follow the platform Terms of Service.
