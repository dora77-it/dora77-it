## 概要
**GordonteのAIキャビネット**は、Whisk AIの作業を自動化するサポートツールです。
繰り返しの画像生成タスクを、より少ない手動操作で実行できます。

## 主な機能
- プロンプトの一括キュー実行
- 生成画像の自動ダウンロード
- 一時的エラー時の自動リトライ
- マルチバージョン実行モード

## 対応言語（3言語のみ）
1. 韓国語
2. 英語
3. 日本語

## クイックスタート（Chrome拡張版）
1. 拡張機能をChrome/Edge/Braveにインストールします。
2. ツールバーから拡張機能を起動します。
3. モード/バージョンを選択します。
4. プロンプトを貼り付けるか `.txt` を読み込みます。
5. **Start** をクリックします。

> 推奨: ブラウザ設定の「ダウンロード前に保存先を確認する」をオフにすると連続保存が安定します。

## 低コスト代替: Chrome拡張なしでも自動化できる？
はい、可能です。Whisk画像生成の**非拡張オートメーション**も構築できます。

- Playwright/Seleniumでブラウザ操作を自動化（入力、実行、保存）
- 小規模バッチと簡易リトライ記録から開始
- 利用規約を守るため、速度制限を設定
